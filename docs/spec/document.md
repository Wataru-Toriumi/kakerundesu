# 文書の編集と保存

起動時は、使い方を記したサンプル文書を「無題.md」として表示する。保存先は未設定で、最初の編集までは「保存済み」と表示する。ヘッダーの「新規」で作る文書の本文は空になる。

## 文書を作る・開く・保存する

| 操作 | 結果 |
| --- | --- |
| 新規（⌘N / Ctrl+N） | 空の「無題.md」に切り替える。ディスク上にファイルができるのは保存先を選んで保存したとき。 |
| 「ファイル」→「ファイルを開く…」（⌘O / Ctrl+O） | ファイル選択ダイアログで1件選び、読み込みに成功すると本文とファイル名が切り替わる。ライブラリの外のファイルも選べる。ツリーのファイルを選んだ場合は直接読み込む。 |
| 保存（⌘S / Ctrl+S） | 保存先が未設定なら「無題.md」を初期名とする保存ダイアログを開く。既に開いたファイルや保存先が決まった文書は、同じパスに上書きする。 |

読み書きする文書はUTF-8で、対応拡張子は `.md`、`.markdown`、`.mdx`。拡張子の英字は大文字・小文字を区別しない。初回保存ダイアログのフィルターは `.md`。保存は利用者が「保存」を実行した時点の本文を対象とする。

## 未保存の変更と中断

| 条件と操作 | 画面で確認できる結果 |
| --- | --- |
| 本文を編集する | ファイル名に「•」が付き、ステータスバーに「未保存の変更があります」と表示する。編集を戻して保存時の本文と一致すると「保存済み」に戻る。 |
| 未保存のまま「新規」、開くファイルの選択、またはツリーからのファイル作成開始を行う | 「保存されていない変更を破棄しますか？」と確認する。拒否すると現在の文書と編集内容を保持する。「開く」ではファイルを選んだ後に確認する。 |
| 開く・保存ダイアログをキャンセルする | 表示中の本文、ファイル名、保存状態を保持する。 |
| 読み込みや保存に失敗する | ステータスバーに操作とエラー理由を表示する。読み込み失敗時は元の文書を表示し、保存失敗時は未保存の編集を保持する。 |
| 保存の完了を待つ間に同じ文書をさらに編集する | 保存開始時の本文をディスクに書き込み、後から加えた編集は画面に未保存の状態で残す。 |

未保存の本文がある状態でウィンドウを閉じる際は、アプリが終了前の確認を要求する。確認ダイアログの表示は実行環境に依存する。
