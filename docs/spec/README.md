# かけるんです 外部仕様

「かけるんです」は、ローカルのMarkdown文書を1件ずつ開き、編集結果をプレビューしながら保存するデスクトップアプリです。ファイルは直接開けます。よく使うフォルダをライブラリに設定すると、その中の文書をツリーから選べます。

| 確認したいこと | 仕様 |
| --- | --- |
| 起動時の文書、対応形式、保存先、未保存の変更を破棄する条件 | [文書の編集と保存](document.md) |
| ツリーに表示される項目、外部からの変更、ファイルやフォルダの作成条件 | [ライブラリ](library.md) |

## 画面構成

| 領域 | 表示と操作 |
| --- | --- |
| ヘッダー | 現在のファイル名と、新規・開く・保存・テーマ切り替えの各ボタン。本文に未保存の変更があるとファイル名の末尾に「•」が付く。 |
| FILES | 選択フォルダのツリー、Markdownファイルの件数、フォルダの選択ボタン。 |
| MARKDOWN | 行番号付きの本文エディタと文字数。文字数は改行を含むUTF-16コード単位で数えるため、例えば「😀」は2文字と表示する。 |
| PREVIEW | 編集中の本文をその場で表示する。GitHub Flavored Markdownの表、タスクリスト、取り消し線に対応する。本文中の生HTMLをHTMLとして描画したり、MDXの式を実行したりする機能はない。 |
| ステータスバー | 保存状態と、直近の操作結果やエラーメッセージ。 |

## ウィンドウとテーマ

初期ウィンドウは1180 × 760、最小サイズは720 × 520。表示幅が720pxを超えると左から、720px以下では上から、FILES・MARKDOWN・PREVIEWの順に並ぶ。境界をドラッグすると各領域の大きさを変更できる。

| 配置 | FILESの初期値（最小値） | MARKDOWN・PREVIEWそれぞれの初期値（最小値） |
| --- | --- | --- |
| 横並び | 幅の18%（12%） | 幅の41%（20%） |
| 縦並び | 高さの25%（15%） | 高さの37.5%（15%） |

初回のテーマはライト。ヘッダーのボタンでライトとダークを切り替えられ、次回起動時も選んだテーマを使う。
