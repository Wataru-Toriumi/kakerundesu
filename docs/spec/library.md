# ライブラリ

## フォルダを選ぶ・文書を探す

FILES上部の「フォルダを開く…」で、一覧の起点となるフォルダを1つ選ぶ。選択後は同じ位置にフォルダ名が表示され、隣のフォルダアイコンから切り替えられる。キャンセルすると現在の選択を保持する。選んだフォルダは次回起動時も復元する。ライブラリを切り替えても、編集中の文書はそのまま表示する。

- 選択フォルダの直下から再帰的に、対応するMarkdownファイルとサブフォルダを表示する。空のサブフォルダも表示する。各階層でフォルダを先に並べ、同じ種類の項目は日本語の名前順に並べる。
- 名前が `.` で始まるサブフォルダ、`node_modules`、`target` は、その配下も一覧から除外する。この除外はフォルダに対するもので、例えば `.memo.md` は表示対象になる。シンボリックリンクの項目は一覧に含めない。
- フォルダ行を選ぶと展開・折りたたみが切り替わる。ファイル行を選ぶと文書を開き、現在開いているファイルに該当する行を強調する。
- FILESの件数は、折りたたんだ階層も含むMarkdownファイル数。読み込み中は「読み込み中」、読み込み後に表示対象が0項目なら「フォルダは空です」と表示する。

フォルダを監視し、対象ファイルの追加・削除・名前変更などの通知を受けると一覧を読み直す。例えば外部で `draft.md` を `final.md` に改名すると、ツリーの表示が変わる。この更新の対象は一覧で、開いている文書の本文や保存先は自動で切り替わらない。選択フォルダ自体を読み込めなかった場合は一覧を空にして理由を表示する。サブフォルダ内の一部を読み取れなかった場合は、取得できた範囲を表示する。

## ツリーから作成する

作成ボタンはツリー内のサブフォルダ行にある。選んだ行の直下が作成先になる。選択フォルダの最上位に文書を置く場合は、ヘッダーの「新規」で文書を作り、初回保存時にそのフォルダを選ぶ。

| 操作 | フォームを開いたとき | 作成に成功したとき |
| --- | --- | --- |
| 新規ファイル | 未保存の文書があれば破棄の確認を行う。作成先を展開し、初期名「無題.md」の入力欄にフォーカスする。 | 空のファイルをディスクに作り、そのファイルをエディタで開いて一覧を更新する。 |
| 新規フォルダ | 作成先を展開し、初期名「新しいフォルダ」の入力欄にフォーカスする。 | サブフォルダを作り、編集中の文書を保持して一覧を更新する。 |

フォームは一度に1つ表示する。入力中にEnterまたは「作成」で確定し、Escまたは「キャンセル」で閉じる。作成前にキャンセルすると、元の文書とディスク上の内容を保持する。

### 名前の扱い

| 入力例・条件 | 結果 |
| --- | --- |
| ファイル名に ` 会議メモ ` と入力 | 前後の空白を取り、拡張子を省略したファイル名には `.md` を補って `会議メモ.md` を作る。 |
| `議事録.MD`、`手順.markdown`、`案.mdx` | 入力した拡張子のまま作る。対応外の拡張子（例：`案.txt`）ではエラーを表示する。 |
| ファイル名・フォルダ名が空または空白のみ | 確定しても作成せず、入力を続けられる。 |
| `.`、`..`、または `/`・`\` を含む名前 | 名前を指定し直せるよう、作成に失敗した理由を表示する。 |
| 同じ場所に同名の項目が既にある | 既存項目を保持し、エラーを表示する。フォームで名前を直して再試行できる。 |

フォルダ名も前後の空白を取り除く。作成には、選択フォルダの内側にある既存の親フォルダと、その場所への書き込み権限が必要になる。
