# Tauriルール

このディレクトリのルールは、`src-tauri/` 配下のRustバックエンドと
Tauri設定に適用する。

変更内容に応じて、以下の詳細ルールを作業前に読むこと。

- Tauriコマンド、frontendの `invoke`、payloadを変更する場合は
  `commands.md` を読むこと。
- ファイル操作、パス検証、capability、権限を変更する場合は
  `security.md` を読むこと。
- Tauri設定、schema、生成物を変更する場合は `generated-files.md` を
  読むこと。

複数の変更に該当する場合は、関連する詳細ルールをすべて読むこと。
