# Git・Pull Requestルール

- 関係のない作業ツリーの変更を保持し、依頼された変更に属するファイルだけを
  ステージすること。
- リポジトリにより具体的な規約がない限り、Conventional Commitsを使用すること。
- ユーザーから明示的な依頼がない限り、amend、rebase、force-push、既存履歴の
  書き換えを行わないこと。
- pushする前に、現在のブランチとリモート追跡ブランチを確認すること。
- 現在のブランチがすでに未完了のPull Requestで使用されている場合、無関係な
  作業を暗黙に追加しないこと。新しいブランチを作成するか、既存PRを更新するか
  ユーザーに確認すること。
- 積み上げPull Requestでは、直前の依存ブランチをbaseとして使用し、その依存を
  PR本文に記載すること。
- PR本文には変更の概要と、実際に実行した検証を記載すること。
