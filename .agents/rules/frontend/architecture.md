# フロントエンドアーキテクチャ

## 責務と構成

- `App.tsx` は画面の構成とドメインHookの接続に集中させること。
  ファイルI/O、永続化、監視処理、その他の機能ロジックを置かないこと。
- 状態と副作用は、単一のまとまったドメイン責務を持つHookへ分離すること。
- 無関係なドメインの状態や操作を、大きなI/Fを通して再公開するだけの
  統合Hookを作らないこと。
- Reactに依存しないユーティリティは `src/lib/` に置くこと。
- 機能の構成は `src/editor/` など、対象機能のディレクトリに置くこと。
- スタイルを持つUI部品は `src/components/` 配下に置くこと。
