# フロントエンドルール

このディレクトリのルールは、`src/` 配下のReact・TypeScript
アプリケーションと、フロントエンド関連の設定に適用する。

変更内容に応じて、以下の詳細ルールを作業前に読むこと。

- `App.tsx`、Hook、状態管理、機能の分割を変更する場合は
  `architecture.md` を読むこと。
- コンポーネント、shadcn/ui、Tailwind、CSS、見た目を変更する場合は
  `components.md` を読むこと。
- props、型、import、データフローを変更する場合は
  `conventions.md` を読むこと。

複数の変更に該当する場合は、関連する詳細ルールをすべて読むこと。
