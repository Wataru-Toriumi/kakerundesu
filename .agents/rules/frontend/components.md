# コンポーネントとスタイル

- 独自の操作部品を実装する前に、適切なshadcn/uiコンポーネントがないか
  確認し、用途に合う場合はshadcn/uiを優先すること。
- `src/components/ui/` はshadcn管理のコードとして扱うこと。プロジェクト
  固有の明確な理由がない限り、生成された構成とファイル構造を維持すること。
- プロジェクト固有のコンポーネントは、1ファイル1コンポーネントとすること。
  `src/components/ui/` に関連プリミティブがまとめて生成される場合は例外とする。
- Tailwindクラスは `src/components/` 配下のコンポーネントを通して適用すること。
  機能モジュールと `App.tsx` では `className` を直接指定せず、スタイル済みの
  コンポーネントを組み合わせること。
- グローバルCSSは、テーマトークン、ベーススタイル、コンポーネント境界では
  スタイルを適用できない外部ライブラリや生成マークアップに限定すること。
  通常のコンポーネントスタイルにはTailwindを優先すること。
- 条件付きクラスやvariantの組み立てには、既存の `cn` を使用すること。
- UIを変更する際は、ライト・ダークテーマとレスポンシブレイアウトを
  維持すること。
